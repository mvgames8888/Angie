# Reportes

Los hallazgos de la auditoría se documentarán en este directorio. Cada hallazgo
debe incluir, como mínimo:

- severidad e impacto económico;
- archivo y líneas exactas del commit auditado;
- precondiciones y escenario de ataque paso a paso;
- prueba de concepto reproducible;
- recomendación de mitigación; y
- pruebas que demuestren la corrección propuesta.
